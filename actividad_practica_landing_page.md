# Actividad Práctica: Creación de una Landing Page

## ¿Qué tal practicar?
¡Bienvenidos a la actividad práctica del módulo! 

### Descripción
En este ejercicio implementaremos los conceptos aprendidos en las clases sobre **Landing Pages**. Utilizaremos **HTML** y **CSS** para crear una Landing Page simple pero efectiva, aplicando los principios de diseño orientado a la conversión y los elementos básicos de una Landing Page.

### Paso a paso

1. **Estructura HTML:** Crea un archivo HTML con las etiquetas necesarias como `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`, etc.
2. **Contenido:** Agrega el contenido básico de la Landing Page como un encabezado, subtítulos, texto descriptivo y una llamada a la acción (CTA).
3. **Estilos CSS:** Crea un archivo CSS y enlázalo con tu archivo HTML. Define estilos para el diseño de la página, como colores, fuentes, márgenes y tamaños de texto.
4. **Diseño Orientado a la Conversión:** Asegúrate de que el diseño de la página esté centrado en la oferta principal y que haya una llamada a la acción clara y relevante.
5. **Optimización:** Verifica que la página sea responsiva y se vea bien en diferentes dispositivos. Ajusta los estilos según sea necesario.
6. **Versionamiento:** Vincula tu proyecto a un repositorio en GitHub.
7. **Deploy:** Aloja tu Landing Page en algún servidor revisado en el curso (Netlify, GitHub Pages, Firebase).

### ¿Cómo presentar su entrega?
Enviar la liga al repositorio en GitHub y la liga del sitio publicado.
